# Clustio

**Clustio** is an automated unsupervised machine learning application designed to perform data clustering on CSV files, evaluate multiple clustering algorithms, and identify the best-performing model through a normalized evaluation score.

![Clustio](https://github.com/user-attachments/assets/6ed3cfea-aa84-43db-a71c-9aa01d0bd77c)

## ⚙️ How It Works

Users can upload a CSV file and explore clustering results through an interactive frontend. Clustio processes the dataset using multiple unsupervised learning algorithms, evaluates their results, and ranks the models based on a combined score.

The application also allows users to export the original dataset with an additional column containing the cluster assignments generated by the highest-scoring model.

## ✨ Features

- **Multiple Clustering Algorithms:** Supports six unsupervised learning algorithms:
    - K-Means++
    - Hierarchical Clustering
    - DBSCAN
    - OPTICS
    - Gaussian Mixture Models (GMM)
    - Spectral Clustering
- **Automated Parameter Search:** Tests predefined parameter configurations for each algorithm to explore different clustering solutions.
- **Model Evaluation:** Evaluates clustering results using three complementary metrics:
    - **Silhouette Score (SS):** Measures how well each sample fits within its assigned cluster compared to neighboring clusters. Higher values indicate better-defined clusters.
    - **Davies-Bouldin Index (DBI):** Evaluates cluster compactness and separation. Lower values indicate better clustering solutions.
    - **Calinski-Harabasz Index (CH):** Measures the ratio between inter-cluster dispersion and intra-cluster dispersion. Higher values generally indicate better-defined clusters.
- **Combined Evaluation Score:** Calculates a normalized and weighted score from the three evaluation metrics, providing a general-purpose criterion for comparing different clustering algorithms and configurations.
- **Dimensionality Reduction:** Automatically applies Principal Component Analysis (PCA) to datasets containing three or more numerical features, generating a two-dimensional representation for visualization.
- **Interactive Cluster Visualization:** Displays clustering results through interactive frontend charts, allowing users to inspect the distribution and separation of cluster assignments.
- **Processed CSV Export:** Generates an updated CSV file containing the original dataset and an additional Group column with the cluster assignments from the highest-scoring model.
- **MongoDB Caching:** Stores uploaded datasets and clustering results in MongoDB, allowing previously processed datasets to reuse cached results when uploaded again under the same filename.

## 🔍 Parameter Search

Clustio uses a simplified parameter search strategy based on predefined configurations for each algorithm. The number of clusters (k) generally ranges from 2 to 10, with additional algorithm-specific parameters evaluated during processing.

The search configuration can be adjusted in *constants.py*.

| Algorithm | Parameters |
|---|---|
| **K-Means++** | Number of clusters (`k`). |
| **Hierarchical** | Linkage methods: `ward`, `complete`, `average`. |
| **DBSCAN** | `min_samples` adjusted according to candidate cluster counts; `eps` optimized using k-nearest-neighbor distances. |
| **OPTICS** | `min_samples` adjusted according to candidate cluster counts; `xi`: `0.03`, `0.05`, `0.1`; `min_cluster_size`: `0.05`, `0.1`, `0.2`. |
| **GMM** | Covariance types: `full`, `tied`, `diag`, `spherical`. |
| **Spectral Clustering** | Affinity: `rbf`, `nearest_neighbors`; gamma: `0.1`, `0.5`, `1.0`. |

## 📊 Understanding the Results

The combined evaluation score provides a general-purpose ranking criterion by normalizing and weighting the three evaluation metrics.

However, a higher score does not necessarily mean that a clustering solution is the most meaningful or useful for a particular dataset.

Clustio intentionally avoids imposing domain-specific assumptions or interpretations on the resulting clusters. Instead, it provides quantitative evaluations and visual representations so users can independently inspect the results and determine whether a particular segmentation is relevant to their objectives.

PCA visualizations provide an additional perspective on cluster distribution, but their two-dimensional representation may not preserve every relationship present in the original feature space.

## 🖥️ Application Controls

- **Insert:** Uploads a CSV file, processes the dataset, stores the results in MongoDB, and displays the clustering evaluations.
- **Inject:** Downloads an updated CSV file containing the original data and the cluster assignments from the highest-scoring model.
- **Reset:** Deletes the MongoDB records associated with the currently selected dataset.

## 🚀 Installation

Clone the repository:

```
git clone https://github.com/aryelsoares/clustio.git
cd clustio
```

Build and start the application:

```docker compose up --build```

Once the containers are running, access the application through:

```http://localhost:3000```

To stop the containers and remove associated Docker volumes:

```docker compose down -v```

**Note:** The -v flag also removes the MongoDB volume, permanently deleting the persisted datasets and clustering results.

## 📝 Notes

Clustio is designed as a tool for automated clustering exploration and model comparison.

Its evaluation score helps organize and compare different clustering solutions, while interactive visualizations allow users to inspect the resulting segments.

The final interpretation and practical relevance of each cluster remain the user's responsibility. Clustio does not attempt to infer business context, assign semantic meaning to clusters, or determine whether a particular segmentation is inherently correct.

The goal is to simplify the clustering workflow while preserving the user's freedom to analyze, interpret, and make decisions based on the results.
